# Grokbot reference kit

Референсы и техническая задача для собственного персонажа MYOR: динамичная форма 1:1, реакции в онбординге и чате, Expo / React Native и веб. Исследование от 6 октября 2026.

**[Открыть галерею](https://alexander-buzaev.github.io/grokbot-reference-kit/)** · **[Задача](TASK.md)** · **[Исследование](RESEARCH.md)**

## Что здесь есть

- Каталог 77 публичных материалов [кейса Novra](https://www.novra.design/case-studies/grokbot): 29 видео, 29 постеров, 18 изображений и ссылка на Rive runtime.
- Галерея с воспроизведением видео из источников и отдельный интерактивный Rive-плеер.
- Результаты проверки веб-Rive: два артборда, 13 View Model properties и переходы работы / ошибки / завершения / загрузки. Native-интеграция пока не проверена.
- Сравнение Rive, процедурной графики и sprite atlas; ссылки на SVG- и Flutter-исследования.
- Конкретная задача: дизайн своего персонажа, проверка рендерера, контракт восьми состояний, интеграция и приёмка.
- Скрипты для локальной выгрузки оригиналов, 29 обзорных раскадровок и 232 кадров с таймкодами.

## Быстрый просмотр

Откройте галерею по ссылке выше. Или клонируйте репозиторий и запустите:

```sh
python3 -m http.server 8770
```

Затем откройте `http://127.0.0.1:8770/index.html`. Требуется сеть: изображения, видео, `.riv` и Rive runtime загружаются из источников. Ссылки принадлежат авторам и могут измениться.

## Локальные раскадровки

Нужны Python 3.9+ и FFmpeg (`ffmpeg`, `ffprobe` в PATH). Сначала скачайте записанные источники; затем экспортируйте кадры и локальную галерею:

```sh
python3 tools/download_assets.py
python3 tools/storyboards.py
python3 tools/build_gallery.py --local
python3 -m http.server 8770
```

Скрипт проверяет SHA-256 относительно исследования. Если источник изменился или недоступен, он сообщает ошибку. Раскадровки — восемь равномерных выборок каждого ролика, а не все авторские ключевые позы. Rive-плеер продолжает загружать оригинал по публичному URL.

`assets/`, `frames/`, `sheets/`, `sources/` исключены из Git. Не публикуйте локально загруженные материалы без необходимых прав. Для восстановления публичной галереи выполните `python3 tools/build_gallery.py`.

## Источники и права

Novra обозначает проект как Independent Concept. Публичная доступность его видео / дизайна / `.riv` не предоставляет лицензию на использование в MYOR. В этом репозитории хранятся собственные документы, скрипты, каталог ссылок и результаты технического исследования; копии сторонних изображений, видео, Rive-файла и нелицензированного кода не включены.

Оригинальный персонаж и motion в кейсе атрибутированы Benji Taylor; notch-концепт — John Bai; развитие концепта — Novra. Атрибуция исходных материалов сохранена в каталоге.

Технические исследования: [Morph Bot](https://github.com/iduu/grokbot-animation), [Flutter GrokBot](https://github.com/nasawz/GrokBot), [Coucou](https://github.com/Louis-CFM/coucou). У каждого свои условия использования; лицензия программного кода не обязательно распространяется на образ персонажа.

Плеер использует [Rive canvas runtime 2.39.2](https://www.npmjs.com/package/@rive-app/canvas), MIT; он загружается с CDN. Для своего продукта предусмотрены собственный дизайн и собственные ассеты.
